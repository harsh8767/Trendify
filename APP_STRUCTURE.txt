🎨 STYLE NAMING SYSTEM
══════════════════════

Screen Name Prefix + Element Name = Style Name

┌─────────────────────────────────────────────────────────┐
│  Screen           │  Prefix              │  Example      │
├───────────────────┼──────────────────────┼───────────────┤
│  Home             │  homeScreen          │  Container    │
│  Categories       │  categoriesScreen    │  Grid         │
│  Cart             │  cartScreen          │  Item         │
│  Profile          │  profileScreen       │  Menu         │
│  Product Detail   │  productDetail       │  Price        │
│  Checkout         │  checkoutScreen      │  Button       │
│  Components       │  [componentName]     │  Wrapper      │
└─────────────────────────────────────────────────────────┘

  cartScreenQuantityButton
